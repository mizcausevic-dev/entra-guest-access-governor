# Kinetic Gain Embedded Tie-back

This repo demonstrates the Entra guest-access governance shape of Kinetic Gain Embedded:

- operator-safe visibility into invitation sprawl, inactive guests, missing reviews, sponsor drift, and cross-tenant trust gaps
- one dashboard joining review ownership, external-collaboration posture, and remediation packets
- a clear path from public proof repo -> paid template -> hosted preview -> embedded product engagement

For embedded product work, the same primitive becomes an in-app B2B identity-governance panel where operators need evidence-rich guest-access visibility without direct access to raw admin consoles or live tenant credentials.
