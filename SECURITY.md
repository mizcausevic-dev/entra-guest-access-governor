# Security Policy

## Data handling

- This repo only ships synthetic Entra guest-access, sponsor, access-review, and cross-tenant trust samples.
- Do not commit live guest user exports, invite emails, tenant IDs, sponsor attributes, or access-review records.
- Microsoft Graph tokens, app secrets, cross-tenant policy exports, and admin credentials must stay outside the repo.

## Claims discipline

- This repo demonstrates governance posture and access-review readiness patterns.
- It does **not** claim certification, production tenant coverage, or live customer enforcement by itself.
